# Windows 12 Desktop

一个 Windows 12 风格的网页桌面，带有 macOS 风格的终端。

## 功能

- Windows 12 风格的桌面界面
- 可拖拽、调整大小的窗口
- macOS 风格的终端（支持基本命令）
- 文件资源管理器
- 设置应用
- 开始菜单
- 任务栏

## 运行

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build
```

## 部署到 Vercel

1. 将代码推送到 GitHub
2. 在 Vercel 导入项目
3. 自动检测 Vite 配置并部署

或使用 Vercel CLI:

```bash
npm i -g vercel
vercel
```
